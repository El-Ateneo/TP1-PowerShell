Trabajo Práctico N.º 1: PowerShell

Módulo: Programación para Seguridad Informática

Docente: Lic. y Prof. Carlos Pacheco

Objetivo

Desarrollar un script en PowerShell para consultar la versión de PowerShell, la política de ejecución, la información del sistema operativo y los datos generales de la computadora mediante el comando systeminfo.

Archivo del trabajo

El script desarrollado para este trabajo práctico se encuentra disponible en el repositorio de GitHub.

Consultar o descargar el script TP1-PowerShell.ps1

Ver repositorio en GitHub

Comandos utilizados

  • $PSVersionTable: información de PowerShell.
  • $PSVersionTable.PSVersion: versión instalada.
  • Get-ExecutionPolicy: política de ejecución actual.
  • Get-CimInstance Win32_OperatingSystem: información del sistema operativo.
  • cmd.exe /c systeminfo: información general del equipo mediante CMD.
