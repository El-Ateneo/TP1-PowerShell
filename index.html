Trabajo Práctico N.º 1: Información del Sistema en PowerShell

Objetivo: Desarrollar un script en PowerShell para consultar la versión del entorno, la política de ejecución activa, la información del sistema operativo y los datos generales del hardware mediante la utilidad de sistema.

📄 Ver script TP1-PowerShell.ps1 🌐 Repositorio TP1 en GitHub

Comandos y variables utilizados:

  • $PSVersionTable: Información general del entorno PowerShell.
  • $PSVersionTable.PSVersion: Muestra la versión específica instalada.
  • Get-ExecutionPolicy: Consulta la política de ejecución de scripts activa.
  • Get-CimInstance Win32_OperatingSystem: Consulta información del sistema operativo.
  • cmd.exe /c systeminfo: Ejecuta el reporte detallado del equipo desde CMD.

Trabajo Práctico N.º 2: Variables, Entradas y Salidas

Objetivo: Implementar captura de datos del usuario por consola para generar un saludo interactivo y calcular el salario a cobrar en función de horas trabajadas y tarifa horaria.

📄 Ver script TP2-PowerShell.ps1 🌐 Repositorio TP2 en GitHub

Comandos y sintaxis utilizados:

  • Read-Host: Solicita y captura la entrada ingresada por el usuario desde la consola.
  • Write-Host: Imprime en pantalla las cadenas y el resultado de las variables procesadas.
  • [double]: Casting de tipo de dato para permitir valores numéricos decimales en el cálculo.
  • $variable = valor: Definición e inicialización implícita de variables en memoria.
  • $horas * $costoHora: Operador aritmético de multiplicación para procesar la paga total.
